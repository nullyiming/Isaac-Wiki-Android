# ⚔️ 《以撒的结合：忏悔》全道具中文图鉴与搜索引擎

> 基于纯前端轻量化架构打造的《以撒的结合：忏悔》（The Binding of Isaac: Repentance）全道具中文图鉴与智能搜索系统。收录全量 **721 个道具**，支持面板属性影响、特殊机制、道具池获取途径与详细成就解锁条件解析。

---

## ✨ 核心特性

- 🎮 **全量 721 道具收录**：覆盖《忏悔》全部 171 个主动道具与 548 个被动道具。
- 📊 **深度数值与机制解析**：
  - 实时解析伤害、射速、移速、射程、幸运、生命值等面板具体加成数值；
  - 标识飞行、追踪、激光、穿透、环绕等特殊机制标签；
  - 详尽解析宝箱房、恶魔房、天使房、隐藏房、星象房、商店、乞丐等全部生成途径。
- 🏆 **全成就解锁指南**：关联 641 项游戏内置成就，明确指出具体角色要求与通关目标。
- ☀️ / 🌙 **白天与黑夜双主题**：根据环境光线自由切换极简白（Day）与深空暗夜（Night）模式。
- 🎬 **实机悬浮动效展示**：鼠标悬停道具卡片时，平滑弹出正方形展示框，动态呈现官方道具底座与循环悬浮呼吸光环。
- ⚡ **毫秒级模糊搜索引擎**：支持中文名、英文名、内部 ID 编号（如 `#1`）、效果机制关键词即时匹配。
- ⌨️ **键盘极速流交互**：支持 `Ctrl + K` / `⌘ K` / `/` 一键呼出搜索，`Esc` 快速关闭。
- 📦 **零依赖纯静态运行**：无需安装 Python、无需后端数据库，双击 `index.html` 即可离线秒开。

---

## 🚀 快速使用

### 1. 本地免安装运行
直接下载仓库，双击打开 `web/index.html` 即可在任意浏览器中使用。

### 2. 本地 Python 启动
```bash
python app.py
```
浏览器访问：`http://localhost:8000`
