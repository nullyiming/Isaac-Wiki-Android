# Isaac-Wiki-Android

> 《以撒的结合》图鉴 —— 本地离线道具查询工具

## 简介

Isaac-Wiki-Android 是一个本地离线的《以撒的结合》道具查询工具，收录主动道具、被动道具、塔罗牌与饰品，方便玩家随时查阅。

**收录游戏版本：** 重生、胎衣、胎衣†、忏悔  
**当前版本：** 1.0
